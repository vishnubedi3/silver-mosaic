# Contributing to Silver Mosaic

Thank you for your interest in contributing to this research project.

## Project Overview

Silver Mosaic is a research monograph evaluating the highest-leverage fields for independent researchers operating with zero budget and legacy hardware. The project recommends Formal Mathematics (Lean 4 / mathlib) as the optimal field.

## How to Contribute

### Reporting Issues

If you find errors, inconsistencies, or areas for improvement in the manuscript:

1. Check existing issues to avoid duplicates
2. Open a new issue with:
   - Clear title describing the problem
   - Specific location in the manuscript (chapter, section, line number)
   - Description of the issue
   - Suggested fix if applicable

### Suggesting Improvements

We welcome suggestions for:
- Factual corrections with citations
- Additional evidence or case studies
- Methodology improvements
- New open problems or research opportunities
- Writing clarity improvements

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b improvement/your-feature`)
3. Make your changes
4. Ensure your changes maintain the manuscript's formatting conventions
5. Submit a pull request with a clear description

## Manuscript Conventions

### Formatting

- Use Markdown for all documents
- Use `$$..$$` for display math, `$...$` for inline math
- Use `[N]` for numbered citations
- Use ASCII art tables where appropriate

### Citations

- All claims must be supported by citations
- Citations use numbered references `[N]` mapped to the bibliography
- Prefer peer-reviewed sources over popular science

### Structure

- Chapters are numbered sequentially (1-25)
- Sections use decimal notation (1.1, 1.2, etc.)
- The manuscript follows a 5-volume architecture (see README.md)

## Code of Conduct

- Be respectful and constructive
- Focus on the evidence, not personal opinions
- Acknowledge uncertainty appropriately
- Distinguish between established evidence, strong inference, and reasoned speculation

## Questions?

Open an issue for any questions about contributing.
